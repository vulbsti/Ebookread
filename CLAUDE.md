Create a epub reader for ubuntu/debian based systems.
The reader must be able to read and handle most formats like fb2, mobi, pdf but importantly handle epub.
The reader must be able to handle various formattings and provide settings for custom format and line space and fontsize and font options in the UI.
The software must have a toggle option for day and night mode a custom mode with slider where user can control the depth of contrast and another slider for color like grayscale and darkness. 
The software must have a navigation button on top right where the user can click to expand and view sections of the book and on clicking those sections the user jumps right into that section. the reader must support links, hyperlink, backlink forward link highlighted in blue, upon clicking the user is taken right to that section of book example table of contents where clicking on a content I can jump into that part.
The reader must remember the page where I last left, and should continue from there next time I open the book and app. The reader must also support a library button where it shows previously opened books and I can select a book and open it and upon opening I am taken to the last page where I left the book. This should be for each book previously opened.

The app must be lightweight use minimal dependencies and should be easily installable on any ubuntu/debian system
